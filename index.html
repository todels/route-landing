02 How it worksPlays on loop while on screen: Scan sweeps the pools, Split sends tokens flowing down each route (line weight = share), Check pops a tick per route, Sign pulses the output. Trade size changes the split: $10 uses one pool, $25,000 splits three ways through a USDG hop. Hover pauses. Pool names are placeholders.
